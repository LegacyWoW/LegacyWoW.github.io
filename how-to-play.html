How to Play

LegacyWoW runs on the 3.3.5a client and progresses from Patch 1.0.0 → 3.3.5a, with custom content introduced along the way.

Follow the steps below to get connected and start playing.

Go to Downloads

1) Download the LegacyWoW Client

Download the LegacyWoW game client and any required files from the Downloads page.

Go to Downloads

2) Install Tailscale

LegacyWoW uses Tailscale to securely connect players to the game server.

You will need to install Tailscale on the computer you use to play LegacyWoW.

Download Tailscale

3) Create a Tailscale Account

Open Tailscale after installing it and create a free Tailscale account.

You do not need to join the LegacyWoW team or manage any additional network settings yourself.

4) Connect to the LegacyWoW Server

Once Tailscale is installed and you have created your account, use the LegacyWoW access link below.

Connect to LegacyWoW

Important: Tailscale must be running while you play LegacyWoW.

The LegacyWoW server uses Tailscale for the game connection. Without Tailscale running, your game client will not be able to reach the server.

5) Set Your Realmlist

Open your LegacyWoW game folder and locate: 

realmlist.wtf

Open the file with Notepad and replace its contents with: 

set realmlist logon-legacywow.tail63bcbc.ts.net

Make sure Tailscale is running before launching the game.

6) Create Your LegacyWoW Account

Create your LegacyWoW game account through the website.

Create Account

Enter your desired username, email address, and password. You will use these credentials to log into the game.

7) Select Optional Patches

Start: 

patchmenu.exe

Use the patch menu to select any optional features you would like to use.

Optional content may include HD models, new mounts, custom models, or other available LegacyWoW features.

Optional patches are not required unless specifically stated.

8) Update the Game

Start: 

WoWLauncher.exe

Allow the launcher to update your LegacyWoW client as needed.

Wait until the launcher has finished before continuing.

9) Launch LegacyWoW

Make sure Tailscale is running and that you have successfully connected to the LegacyWoW server.

Launch: 

wow.exe

Log in using the LegacyWoW account you created on the website.

Quick Start

  1. Download the LegacyWoW client.
  2. Install Tailscale.
  3. Create a free Tailscale account.
  4. Click Connect to LegacyWoW.
  5. Make sure Tailscale is running.
  6. Set your realmlist.wtf to logon-legacywow.tail63bcbc.ts.net.
  7. Create your LegacyWoW account.
  8. Run patchmenu.exe for optional patches.
  9. Run WoWLauncher.exe to update.
  10. Launch wow.exe.

Having Trouble Connecting?

Make sure:

  • Tailscale is installed and running.
  • You have used the LegacyWoW access link.
  • The LegacyWoW server is available in Tailscale.
  • Your realmlist.wtf contains the correct address.
  • You are using the LegacyWoW 3.3.5a client.
  • Your game files have finished updating.

If you still cannot connect, visit the FAQ or contact the LegacyWoW team.
